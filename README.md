# yuchen-site

Personal portfolio site built with plain HTML, CSS and a little vanilla JS. No frameworks, no build step.

## Structure

Site files live in `public/`.

## Local preview

Open `public/index.html` in a browser, or serve the folder:

```sh
npx serve public
```

## Deploy

Pushing to `main` triggers a GitHub Actions workflow that publishes `public/` to GitHub Pages.
